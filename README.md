# ENTEC — As built externo

Portal documental em HTML único para ENTEC SERVIÇOS E LOCAÇÕES DE EQUIPAMENTOS LTDA.

## Conteúdo

- 8 pranchas PDF, com consulta e download dos originais.
- 5 desenhos DWG incorporados para download.
- 7 registros fotográficos.
- Busca, filtros, catálogo CSV e resumo para impressão.

Abra `index.html` em um navegador ou consulte o site publicado pelo GitHub Pages. O acervo incorporado funciona offline; o link para a pasta de origem exige internet e as permissões correspondentes.

## Referências

Projeto legal as built R02/2024 e projeto executivo de ampliação R01/2026. Divergências documentais estão indicadas no portal. O acervo não atesta execução atual, aprovação ou situação de licenciamento. A condição executada depende de conferência de campo e validação técnica.
